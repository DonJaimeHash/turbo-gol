# Name and logo policy

The code of Turbogol is free software under the AGPL-3.0: you can use, study, change and share it.
The **name "Turbogol" and its logo** are a separate matter: they tell players which game and which
servers are the community's official ones. This short policy keeps that clear without getting in
the way of anyone.

You **can**, without asking:

- Use the name to refer to the project ("a mod for Turbogol", "compatible with Turbogol", "based on Turbogol").
- Run unmodified copies, or copies whose changes are only bug fixes, under the name Turbogol.
- Use the name and logo in articles, videos, streams, tutorials and fan art.

Please **use a different name** (and say "based on Turbogol" if you like) when you:

- Publish or host a fork with changed gameplay, rules or content.
- Run a public server or a commercial service that is not the community's.

Never use the name or the logo in a way that suggests the project endorses you or your product when
it does not. If you are unsure, open a Discussion and ask.
