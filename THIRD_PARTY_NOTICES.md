| Component | Used for | License | Where |
|---|---|---|---|
| [RocketSim](https://github.com/ZealanL/RocketSim) 2.2.1 | Vehicle and ball physics, compiled to WebAssembly (`src/sim/wasm/rocketsim.wasm`) | MIT | git submodule `native/RocketSim`; two small patches in `native/patches/` |
| [Bullet Physics](https://github.com/bulletphysics/bullet3) 3.24 (as modified by RocketSim) | Collision detection and rigid-body dynamics inside RocketSim | zlib | inside the RocketSim submodule (`libsrc/bullet3-3.24`) |
| [three.js](https://github.com/mrdoob/three.js) r186 | WebGPU / WebGL2 renderer | MIT | npm dependency `three` |
| [Emscripten](https://emscripten.org/) runtime (JS glue `src/sim/wasm/rocketsim.js`) | Loads and runs the WebAssembly module | MIT (or UIUC/NCSA) | generated by the Emscripten SDK |
| [musl libc](https://musl.libc.org/) (as shipped with Emscripten) | C standard library compiled into the wasm | MIT | inside `rocketsim.wasm` |
| [LLVM libc++ / libc++abi](https://libcxx.llvm.org/) (as shipped with Emscripten) | C++ standard library compiled into the wasm | Apache-2.0 WITH LLVM-exception | inside `rocketsim.wasm`; the LLVM exception waives the attribution requirement for compiled code |

Altered versions: RocketSim and its bundled Bullet are compiled with the patches in
`native/patches/` (a faster broadphase triangle query in Bullet and a deterministic car iteration
order in RocketSim). They are marked with `// PATCH` comments in the patched files and described
in `native/README.md`, as the zlib license asks for altered sources.

Development tools (Vite, TypeScript, Wrangler, the Emscripten compiler) are not distributed with the
game; only the Emscripten runtime and the standard libraries listed above end up in the build.
