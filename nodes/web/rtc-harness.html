      Cómo usarla

      1. Armá el bundle: npm run build:web
      2. Levantá el plano de control: npm run control
      3. Desde /host, sacá un token para la región SA y corré un nodo casero con --transport rtc. Esperá a que pase la prueba de WebRTC (estado en prueba).
      4. Abrí esta página desde el plano de control (/web/rtc-harness.html) y tocá el botón. Con ?auto=1 arranca sola.

      Juega unos 8 segundos, sale, y espera a que el sitio re-simule la partida para verificarla. El resumen para pruebas automáticas queda en window.__harness y el estado en body[data-state].
