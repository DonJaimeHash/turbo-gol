# Turbogol

**A fast physics car-soccer game that runs in your browser.** Drive, jump, fly with boost and score
goals in 1v1, 2v2 or 3v3, against bots or other players online. Everything you see and hear (field,
cars, ball, stadium, sky, sounds) is generated by code; the one exception is a 6 KB subset of a free
font (Barlow Condensed, SIL Open Font License) for the titles.

**Play now: [turbo-gol.com](https://turbo-gol.com)** · Community: [Discord](https://discord.gg/sPyf787aHP)

[Leer en español](README.es.md) · [Contributing](CONTRIBUTING.md) · [Architecture](ARCHITECTURE.md) · License: [AGPL-3.0](LICENSE)

## Features

- **Physics at 120 Hz in WebAssembly**: rigid-body car and ball physics from the open-source
  [RocketSim](https://github.com/ZealanL/RocketSim) library (on Bullet), compiled with Emscripten.
- **Modern rendering**: three.js `WebGPURenderer` with procedural TSL materials, bloom and a WebGL2
  fallback; two quality tiers.
- **Modes**: matches against bots (three difficulties, team AI with rotations), free practice and
  nine training packs (shooting, saving, aerials).
- **Online**:
  - casual play on a peer-to-peer rollback mesh over WebRTC (GGPO-style, inputs only);
  - server-hosted matches with client prediction;
  - several playlists at once and region choice;
  - custom lobbies: public list, join by code, password, team picks.
- **Accounts and ranked**: an email confirmed with a code, plus a password (optional Google /
  Discord); one email, one account. Accounts made with a username before keep it until the cutoff
  the owner announces. Ranked play gives a rating
  per playlist (Weng-Lin / OpenSkill model), with placement games, tiers, leaderboards and abandon
  penalties. Guests can play everything except ranked.
- **Experimental features** (signed-in players, Settings > Experimental): the Super low graphics
  quality, and physics presets (gravity, ball and car speed, boost, jumps, bumps...) for free play
  and custom P2P lobbies. They never count for rank or stats ([docs/experimental.md](docs/experimental.md)).
- **Controls**: keyboard + mouse and gamepad at the same time, every action rebindable, camera and
  sensitivity settings.
- **Cheap to host**: the backend runs on Cloudflare Workers + Durable Objects with spend caps in the
  code (`docs/online/DECISIONS.md`).

## Quick start

Requirements: Node.js 24+ and a browser with WebGPU (Chrome / Edge 113+, Firefox 141+, Safari 26+)
or at least WebGL2.

```sh
git clone --recurse-submodules https://github.com/DonJaimeHash/turbo-gol.git
cd turbo-gol
npm install
npm run dev        # http://localhost:5173 — offline modes work right away
```

Online modes need the local backend (no Cloudflare account required):

```sh
cd server
npm install
cp .dev.vars.example .dev.vars   # set JWT_SECRET to any long random string
npm run dev                      # wrangler dev on http://127.0.0.1:8787 (Vite proxies to it)
```

## Useful commands

| Command | What it does |
|---|---|
| `npm run dev` | Game with hot reload |
| `npm test` | Node tests: physics bridge, field, bots, match rules, training, input, net, menus |
| `npm run typecheck` | TypeScript check |
| `npm run build` | Production bundle in `dist/` (includes the license notices) |
| `npm run smoke:match` | Headless bots-vs-bots match, prints touches / goals / speed |
| `npm run build:wasm` | Rebuild the physics WebAssembly (needs the Emscripten SDK, see `native/README.md`) |
| `cd server && npm test` | Backend unit tests |
| `node server/test/smoke-accounts.mjs` | End-to-end test of accounts, ranked and lobbies against `wrangler dev` |

## Controls (defaults, all rebindable)

| Action | Keyboard + mouse | Gamepad |
|---|---|---|
| Throttle / reverse | W / S (or ↑ / ↓) | RT / LT |
| Steer, air yaw | A / D (or ← / →) | Left stick |
| Jump, double jump, flip | Right mouse button | A |
| Boost | Left mouse button | B |
| Slide / air roll | Left Shift | X |
| Ball camera | Space | Y |
| Scoreboard | Tab | Back |
| Pause | Esc | Start |

The mouse turns the camera once you click the field (pointer lock). A keyboard-only preset is in
**Configuración → Keyboard & Mouse**. In the pause menu Esc, Start, B and Backspace go back to the
match; only QUIT leaves it. Training: Backspace resets the shot or the ball, Page Up / Page Down pick
the shot, F puts the car back and T toggles unlimited boost in free play.

## How it is built

```
src/sim      physics bridge (WebAssembly), field constants and the procedural field mesh
src/game     game loop at 120 Hz, match rules, training
src/render   three.js renderer, cars, ball, effects, HUD
src/ai       bots and team AI
src/net      online client: P2P rollback, server client, accounts, lobbies
src/ui       menus
server/      Cloudflare Workers backend (matchmaking, signaling, server matches, accounts, lobbies)
nodes/       community-run match servers (prototype, not wired in yet): see nodes/README.md
native/      C++ wrapper around the physics library (RocketSim is a git submodule)
tests/       node tests
docs/        design notes of the online modes and accounts
```

See [ARCHITECTURE.md](ARCHITECTURE.md) for the details and the determinism rules that online play
depends on.

## Deploying your own server

`npm run deploy` builds the game and deploys one Cloudflare Worker that serves the game, the API and
the match sockets (the official one runs on the custom domain [turbo-gol.com](https://turbo-gol.com)).
Before deploying a fork, change the Worker name, the custom domain (`routes`), the KV namespace id,
the Turnstile site key and `VITE_ORIGINS` in `server/wrangler.jsonc`, and set the secrets with
`cd server && npx wrangler secret put JWT_SECRET` (plus `TURNSTILE_SECRET`, the optional OAuth secrets
from `docs/online/ACCOUNTS.md` and the optional `TURN_KEY_ID` / `TURN_KEY_TOKEN` relay pair).
Commit and push the `server/wrangler.jsonc` changes first: the deploy only runs from a clean tree at
`origin/main`.
Without community nodes of your own, deploy with `npm run deploy -- --nodes-off` (the deploy checks
the node release first, so even then its token needs R2 read access, with R2 enabled on the account:
`server/README.md`). The AGPL asks public servers running modified code to offer that source
to their players: keep the menu's "Source code" link (`SOURCE_URL` in `src/brand.ts`; the text is
`menu.source` in every locale, "Código fuente" in Spanish) pointing at your fork.
